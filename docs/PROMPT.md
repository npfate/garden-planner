# GardenPlanner Pro — Техническое задание

## Что это
Кроссплатформенное веб-приложение для планирования садового участка. 
Пользователь рисует схему участка, расставляет деревья/грядки/теплицы, 
ведет историю по годам, учитывает урожай и оценивает сорта.

## Целевая аудитория
Я + мои родители. Интерфейс должен быть простым, с крупными кнопками.

## Ключевые функции

### 1. Схема участка (Canvas)
- Вид схемы — только сверху, без 3D-эффектов
- Все объекты на схеме должны быть маленькими метками 10x10 px, окрашенными в разные контрастные цвета для быстрого распознавания
- Загрузка фонового изображения (фото/кадастровая карта) с кнопкой "замок" 
  (закрепить фон, чтобы не двигался)
- Сетка с настраиваемым шагом (в метрах), линейки сверху и слева
- Привязка объектов к сетке (вкл/выкл)
- Масштабирование (колесо мыши, кнопки +/−)
- Инструменты рисования: прямоугольник, линия, круг, текст, ластик
- При переключении между инструментами существующие объекты на canvas не стираются и не пересоздаются; добавление объекта происходит только при клике по пустому месту в активном режиме инструмента

### 2. Объекты на схеме
- **Плодовые деревья** (яблони, вишни, сливы и т.д.) 
  — с возможностью прививки НЕСКОЛЬКИХ сортов на одно дерево
- **Саженцы** (овощи, ягоды) — можно размещать на грядках
- **Грядки и теплицы** — произвольных размеров, внутрь можно класть саженцы
- **Другое**: дорожки, постройки, пользовательские объекты

### 3. Система годов (ретроспектива)
- Переключатель годов сверху справа: [◄] [2024 ▼] [►]
- При переключении года показываются только объекты этого года
- Объекты прошлых лет, которые еще существуют — полупрозрачные

### 4. Учет урожая и оценки
- Для каждого объекта/сорта можно записать урожай (кг)
- Кнопки 👍 Лайк / 👎 Дизлайк для сорта
- Отдельная вкладка со списком понравившихся / не понравившихся сортов

### 5. Инвентарь (левая панель)
- Предустановленные объекты (яблоня, груша, томат, огурец и т.д.)
- Возможность добавить свои объекты с иконкой

### 6. Дополнительные вкладки (слева)
- **Схема** — список проектов
- **Инвентарь** — библиотека объектов
- **Отчёты** — автогенерируемые отчеты по посадкам/урожаю
- **Записи** — садовый дневник с календарем
- **Планировщик** — календарь посадок, напоминания
- **Настройки** — интерфейс, сетка, экспорт

### 7. Сохранение
- Собственный формат файла .garden (JSON, похожий на XML по структуре)
- Сохранение в файл (не только в браузере)
- Автосохранение каждые 5 минут

### 8. Печать и экспорт
- Печать схемы (A4, A3)
- Экспорт в PDF
