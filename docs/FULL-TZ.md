## 1. ОБЩЕЕ ОПИСАНИЕ
Кроссплатформенное приложение для планирования садового участка с возможностью визуального проектирования, ведения истории посадок по годам, учета урожая и оценки сортов. Приложение должно работать как десктопное приложение (Electron) и как веб-приложение с возможностью совместного редактирования.

---

## 2. ТЕХНОЛОГИЧЕСКИЙ СТЕК

### Frontend:
- **Electron** (для десктоп-версии)
- **React 18+** с **TypeScript**
- **Fabric.js** или **Konva.js** (для canvas-рисования)
- **TailwindCSS** (стилизация)
- **Zustand** или **Redux Toolkit** (state management)
- **Yjs** (для совместного редактирования)
- **React Router** (навигация)

### Backend (для веб-версии):
- **Node.js + Express** или **NestJS**
- **PostgreSQL** + **Prisma ORM**
- **WebSocket** (для real-time sync через Yjs)
- **JWT** (аутентификация)

### Хранение данных:
- **Локально**: IndexedDB (веб) / File System (Electron)
- **Сервер**: PostgreSQL
- **Формат файла**: Собственный XML-подобный формат (.garden)

### Развертывание:
- **Docker** + **Docker Compose**
- **Electron Builder** (для создания исполняемых файлов)

## 4. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

### 4.1. Работа со схемой (Canvas)

#### 4.1.1. Фоновое изображение
- Кнопка "Загрузить фон"
- Поддержка форматов: PNG, JPG, SVG
- После загрузки - кнопка "Закрепить" (замок)
- Закрепленный фон нельзя редактировать, только перемещать/масштабировать
- Возможность скрыть/показать фон
- Регулировка прозрачности фона

#### 4.1.2. Сетку и линейки
- Включаемая/выключаемая сетка
- Настройка шага сетки (1м, 5м, 10м и т.д.)
- Линейки сверху и слева (в метрах)
- Привязка объектов к сетке (вкл/выкл)
- Визуальное отображение привязки (подсветка)

#### 4.1.3. Масштабирование
- Zoom in/out (колесико мыши, кнопки, Ctrl+/-)
- Минимальный масштаб: 10%
- Максимальный масштаб: 500%
- Плавное масштабирование
- Отображение масштаба в %

#### 4.1.4. Инструменты рисования
- **Карандаш**: свободное рисование линий
- **Линия**: прямые линии с указанием длины
- **Прямоугольник**: с указанием размеров (длина × ширина)
- **Круг/Эллипс**: с указанием радиуса/диаметра
- **Текст**: добавление текстовых подписей
- **Ластик**: удаление объектов
- **Выделение**: перемещение, изменение размера, поворот объектов
- **Группировка**: объединение объектов в группы

### 4.2. Объекты на схеме

#### 4.2.1. Плодовые деревья
- Иконки деревьев разных типов (яблоня, груша, вишня и т.д.)
- При размещении открывается диалог:
  - Название дерева (например, "Яблоня у забора")
  - **Сорта** (можно добавить несколько - для прививки):
    - Название сорта
    - Год прививки
    - Заметки
  - Год посадки
  - Диаметр кроны (в метрах)
  - Расстояние до других объектов
- На схеме отображается:
  - Иконка дерева
  - Название
  - Круг (диаметр кроны) - опционально
- При клике на дерево - открывается карточка с информацией

#### 4.2.2. Саженцы
- Иконки саженцев (разные типы: овощные, ягодные, цветочные)
- При размещении:
  - Название культуры
  - Сорт
  - Количество саженцев
  - Схема посадки (расстояние между саженцами)
  - Год посадки
- Возможность размещения **на грядках** (привязка к грядке)
- На схеме отображается:
  - Иконка саженца
  - Название сорта
  - Количество

#### 4.2.3. Грядки
- Инструмент "Грядка" (прямоугольник произвольного размера)
- При создании:
  - Название (например, "Грядка №1")
  - Размеры (длина × ширина в метрах)
  - Форма (прямоугольник, квадрат, произвольная)
  - Тип почвы
  - Год создания
- Внутри грядки можно размещать саженцы
- На схеме отображается:
  - Контур грядки
  - Название
  - Размеры
  - Саженцы внутри

#### 4.2.4. Теплицы
- Аналогично грядкам, но с иконкой теплицы
- Можно размещать саженцы внутри
- Указание типа теплицы (пленочная, стеклянная, поликарбонат)

#### 4.2.5. Другие объекты
- Дорожки
- Постройки (сарай, беседка)
- Водоемы
- Компостная куча
- Пользовательские объекты (можно загрузить свою иконку)

### 4.3. Система годов (Ретроспектива)

#### 4.3.1. Структура данных
Каждый объект привязан к году:
```typescript
interface GardenObject {
  id: string;
  type: 'tree' | 'seedling' | 'bed' | 'greenhouse' | 'other';
  year: number; // год, когда объект был добавлен
  name: string;
  // ... другие поля
  history: {
    [year: number]: {
      // Изменения объекта по годам
      varieties?: string[]; // сорта (для деревьев)
      harvest?: number; // урожай в кг
      rating?: 'like' | 'dislike' | null;
      notes?: string;
    }
  }
}
```

#### 4.3.2. Переключение годов
- При выборе года отображаются только объекты этого года
- Объекты прошлых лет отображаются полупрозрачными (если они еще существуют)
- Можно добавить новый год (кнопка "+")
- Стрелки ◄ ► для быстрого переключения

#### 4.3.3. Сравнение годов
- Возможность включить режим "Сравнение"
- Отображение двух лет одновременно (слева/справа или наложением)

### 4.4. Учет урожая и оценка сортов

#### 4.4.1. Запись урожая
- В правой панели (параметры объекта) - поле "Урожай"
- Вводится в кг (или штуках для мелких культур)
- Можно указать дату сбора
- Автоматически сохраняется в историю года

#### 4.4.2. Оценка сортов (Лайк/Дизлайк)
- В параметрах объекта кнопки: 👍 Лайк / 👎 Дизлайк
- Оценка привязывается к сорту и году
- Можно добавить текстовый комментарий

#### 4.4.3. Вкладка "Избранные сорта"
- Автоматически формируется список:
  - **Понравившиеся сорта** (все лайки за все годы)
  - **Не понравившиеся сорта** (все дизлайки)
- Сортировка по количеству лайков/дизлайков
- Фильтр по году, типу культуры
- При клике на сорт - переход к объекту на схеме

### 4.5. Система инвентаря

#### 4.5.1. Предустановленные объекты
При первом запуске загружается базовый набор:
- **Деревья**: Яблоня, Груша, Вишня, Слива, Абрикос, Черешня
- **Саженцы**: Томат, Огурец, Перец, Клубника, Малина, Смородина
- **Грядки**: Прямоугольная грядка, Высокая грядка
- **Теплицы**: Пленочная теплица, Поликарбонатная теплица
- **Другое**: Дорожка, Сарай, Компост

#### 4.5.2. Добавление своих объектов
- Кнопка "Добавить объект"
- Диалог:
  - Название
  - Категория
  - Иконка (загрузить свою или выбрать из библиотеки)
  - Параметры (какие поля будут при размещении)
- Сохраняется в локальную библиотеку пользователя

### 4.6. Отчеты

#### 4.6.1. Автоматически генерируемые отчеты
- **Отчет по посадкам за год:**
  - Список всех объектов
  - Сорта
  - Количество
  - Общая площадь посадок
- **Отчет по урожаю:**
  - Суммарный урожай по культурам
  - Сравнение с прошлым годом
  - Самые урожайные сорта
- **Статистика по сортам:**
  - Топ-10 понравившихся сортов
  - Топ-10 не понравившихся сортов
  - Средняя урожайность по сортам
- **Севооборот:**
  - Что где росло за последние N лет
  - Рекомендации по чередованию культур

#### 4.6.2. Экспорт отчетов
- PDF
- Excel (CSV)
- Печать

### 4.7. Садовый дневник (Вкладка "Записи")

#### 4.7.1. Создание записи
- Дата (автоматически или выбор)
- Заголовок
- Текст (rich text editor)
- Прикрепление фото
- Привязка к объекту на схеме (опционально)
- Теги (полив, подкормка, обрезка и т.д.)

#### 4.7.2. Календарь
- Визуальный календарь с отметками дней, когда были записи
- Фильтр по тегам
- Поиск по тексту

#### 4.7.3. Ретроспектива
- Просмотр записей за конкретный день в прошлые годы
- Сравнение "что делали в этот день год назад"

### 4.8. Планировщик

#### 4.8.1. Календарь посадок
- Ввод дат посадки для каждого сорта
- Автоматический расчет сроков посадки на основе региона
- Напоминания

#### 4.8.2. Планирование ухода
- Расписание полива
- Расписание подкормок
- Расписание обрезки
- Уведомления (email/push для веб-версии)

### 4.9. Сохранение и загрузка файлов

#### 4.9.1. Собственный формат (.garden)
Структура файла (XML-подобный):
```xml
<?xml version="1.0" encoding="UTF-8"?>
<garden version="1.0">
  <metadata>
    <name>Мой участок</name>
    <created>2024-01-15</created>
    <author>Иван Иванов</author>
  </metadata>
  
  <settings>
    <grid step="1" unit="meter" visible="true" snap="true"/>
    <scale>100</scale>
    <currentYear>2024</currentYear>
  </settings>
  
  <background>
    <image src="data:image/png;base64,..." locked="true" opacity="0.5"/>
  </background>
  
  <objects>
    <object id="1" type="tree" year="2020">
      <name>Яблоня у забора</name>
      <position x="150" y="200"/>
      <size width="50" height="50"/>
      <properties>
        <variety>Антоновка</variety>
        <variety year="2022">Белый налив</variety>
        <crownDiameter>3</crownDiameter>
      </properties>
      <history>
        <year value="2023">
          <harvest unit="kg">45</harvest>
          <rating>like</rating>
          <notes>Отличный урожай</notes>
        </year>
        <year value="2024">
          <harvest unit="kg">52</harvest>
          <rating>like</rating>
        </year>
      </history>
    </object>
    
    <object id="2" type="bed" year="2024">
      <name>Грядка №1</name>
      <position x="300" y="400"/>
      <size width="200" height="100"/>
      <seedlings>
        <seedling id="3" type="tomato">
          <variety>Бычье сердце</variety>
          <quantity>10</quantity>
        </seedling>
      </seedlings>
    </object>
    
    <!-- Другие объекты -->
  </objects>
  
  <diary>
    <entry date="2024-05-15">
      <title>Посадка томатов</title>
      <content>Высадил томаты в теплицу...</content>
      <tags>посадка,томаты</tags>
    </entry>
  </diary>
  
  <inventory>
    <customObject id="101">
      <name>Моя теплица</name>
      <icon>data:image/png;base64,...</icon>
      <category>greenhouse</category>
    </customObject>
  </inventory>
</garden>
```

#### 4.9.2. Локальное сохранение
- **Electron**: сохранение в файловую систему (кнопка "Сохранить как...")
- **Веб**: сохранение в IndexedDB + возможность экспорта файла

#### 4.9.3. Автосохранение
- Каждые 5 минут
- Индикатор сохранения в интерфейсе

### 4.10. Совместное редактирование (Веб-версия)

#### 4.10.1. Шаринг по ссылке
- Кнопка "Поделиться"
- Генерация уникальной ссылки
- Настройка прав доступа:
  - **Только просмотр** (view)
  - **Просмотр и редактирование** (edit)
  - **Полный доступ** (owner)
- Возможность отозвать доступ

#### 4.10.2. Real-time синхронизация
- Использование **Yjs** (CRDT библиотека)
- Все изменения синхронизируются в реальном времени
- Отображение курсоров других пользователей
- Отображение имен пользователей

#### 4.10.3. История изменений
- Кто и что изменил
- Возможность отката к предыдущей версии

### 4.11. Печать

#### 4.11.1. Настройки печати
- Выбор формата (A4, A3, A2)
- Ориентация (книжная/альбомная)
- Масштаб (вписать в страницу / оригинальный размер)
- Что печатать:
  - Только схему
  - Схему + легенду
  - Схему + отчет

#### 4.11.2. Экспорт в PDF
- Высокое качество (300 DPI)
- Все слои включены
- Масштабная линейка

## 14. ДОПОЛНИТЕЛЬНЫЕ ПРИМЕЧАНИЯ ДЛЯ ИИ-АГЕНТА

### 14.1. Приоритеты разработки
1. **Критично**: Canvas с рисованием, сетка, масштабирование
2. **Важно**: Объекты (деревья, грядки), система годов, сохранение файлов
3. **Желательно**: Учет урожая, отчеты, дневник
4. **Опционально**: Совместное редактирование, Docker

### 14.2. Ключевые решения
- **Canvas библиотека**: Fabric.js (более зрелая, больше возможностей) vs Konva.js (проще, легче)
  - **Рекомендация**: Fabric.js для десктопа, Konva.js для веба (если будет разница в производительности)
  
- **State management**: Zustand (проще, меньше boilerplate) vs Redux Toolkit (более предсказуемый)
  - **Рекомендация**: Zustand для начала, переход на Redux если проект вырастет

- **Real-time sync**: Yjs (CRDT, работает offline) vs Socket.io (проще, но нет offline)
  - **Рекомендация**: Yjs (лучше для совместного редактирования документов)

- **База данных**: PostgreSQL (надежная, мощная) vs SQLite (проще для начала)
  - **Рекомендация**: PostgreSQL для продакшена, SQLite для разработки

### 14.3. Потенциальные проблемы и решения
1. **Производительность canvas при большом количестве объектов**
   - Решение: Виртуализация (рендерить только видимые объекты), кэширование

2. **Конфликты при совместном редактировании**
   - Решение: Yjs автоматически разрешает конфликты через CRDT

3. **Размер файлов .garden**
   - Решение: Сжатие (gzip), хранение изображений отдельно (base64 только для маленьких)

4. **Кроссплатформенность Electron**
   - Решение: Тестирование на всех платформах, использование electron-builder

5. **Масштабирование и точность**
   - Решение: Использовать метрическую систему, хранить координаты в метрах, конвертировать в пиксели при рендеринге

### 15.1. Базовая структура компонента Canvas (React + Fabric.js)

```typescript
import { useEffect, useRef } from 'react';
import { fabric } from 'fabric';

interface CanvasProps {
  width: number;
  height: number;
  gridStep: number; // в метрах
  scale: number;
}

export const GardenCanvas = ({ width, height, gridStep, scale }: CanvasProps) => {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const fabricRef = useRef<fabric.Canvas | null>(null);

  useEffect(() => {
    if (!canvasRef.current) return;

    // Инициализация Fabric.js canvas
    fabricRef.current = new fabric.Canvas(canvasRef.current, {
      width,
      height,
      backgroundColor: '#f5f5f5',
      selection: true,
    });

    // Добавление сетки
    drawGrid(fabricRef.current, gridStep, scale);

    return () => {
      fabricRef.current?.dispose();
    };
  }, [width, height, gridStep, scale]);

  const drawGrid = (canvas: fabric.Canvas, step: number, scale: number) => {
    const gridSize = step * scale; // пиксели
    const canvasWidth = canvas.getWidth();
    const canvasHeight = canvas.getHeight();

    // Удаляем старую сетку
    canvas.getObjects().forEach(obj => {
      if (obj.get('isGrid')) canvas.remove(obj);
    });

    // Рисуем вертикальные линии
    for (let i = 0; i < canvasWidth / gridSize; i++) {
      const line = new fabric.Line([i * gridSize, 0, i * gridSize, canvasHeight], {
        stroke: '#ddd',
        selectable: false,
        evented: false,
        isGrid: true,
      });
      canvas.add(line);
    }

    // Рисуем горизонтальные линии
    for (let i = 0; i < canvasHeight / gridSize; i++) {
      const line = new fabric.Line([0, i * gridSize, canvasWidth, i * gridSize], {
        stroke: '#ddd',
        selectable: false,
        evented: false,
        isGrid: true,
      });
      canvas.add(line);
    }

    canvas.sendToBack(canvas.getObjects().find(obj => obj.get('isGrid'))!);
  };

  return <canvas ref={canvasRef} />;
};
```

## 16. ЗАКЛЮЧЕНИЕ

Это техническое задание описывает полноценное кроссплатформенное приложение для планирования садового участка. Приложение должно:

1. **Визуально проектировать участок** с помощью canvas-инструментов
2. **Вести историю посадок** по годам с возможностью ретроспективного просмотра
3. **Учитывать урожай** и оценивать сорта (лайк/дизлайк)
4. **Работать локально** (Electron) и **онлайн** (веб с совместным редактированием)
5. **Сохранять данные** в собственном формате (.garden)

**Технологический стек:**
- Frontend: React + TypeScript + Fabric.js + TailwindCSS
- Backend: Node.js + Express + PostgreSQL + Prisma
- Real-time: Yjs + WebSocket
- Desktop: Electron
- Deployment: Docker

**Ожидаемое время разработки:** 14-19 недель (3.5-4.5 месяца) для одного разработчика.
