# Перевод интерфейса (i18n) — руководство для сообщества

Все строки пользовательского интерфейса вынесены в словарь
[`src/i18n/ru.ts`](../src/i18n/ru.ts) в формате `ключ: значение`.

## Как добавить новый язык

1. Скопируйте `src/i18n/ru.ts` → `src/i18n/<код-языка>.ts` (например `en.ts`).
2. Переведите значения, **не меняя ключи**. Тип `Dictionary` заставит TS
   сообщить о пропущенных ключах.
3. Зарегистрируйте словарь в `dictionaries` в `src/i18n/index.ts`.
4. Откройте PR с пометкой `[i18n]` — см. RULES.md (Conventional Commits).

## Соглашения

| Правило | Пример |
|---|---|
| Ключ = `<раздел>.<элемент>` | `toolbar.zoomIn`, `properties.harvestTotal` |
| Разделы | `nav`, `pages`, `toolbar`, `tool`, `canvas`, `year`, `properties`, `activity`, `inventory`, `errors` |
| Подстановки в `{фигурных скобках}` | `'Пересажен {date}'` |
| Tooltip и aria-label — отдельные ключи | `properties.ratingLike` / `properties.ratingLikeAria` |
| Ключи не переименовывать без миграции переводов | — |

## Интерполяция

```ts
import { t } from '../i18n';
t('properties.transplantedAt', { date: '12.08.2026' }); // «Пересажен 12.08.2026»
```

## Что пока остаётся за пределами словаря

* Названия типов объектов в пользовательском инвентаре (созданные самим
  пользователем) — это данные, а не интерфейс; они хранятся в проекте `.garden`.
* Даты форматируются утилитой `formatDateRu` — для других локалей потребуется
 Intl-версия (задача на будущее).
