## 1. Повороты объектов с привязкой к сетке (snap to grid) — протестировать и доработать

**Статус:** частично реализовано (исправление `fix: корректная привязка к сетке повёрнутых объектов (90/180/270°)`), требуется регрессионное тестирование и возможная доработка.

### Контекст
При включённой привязке к сетке поворот объекта на произвольный угол ломал корректность «прилипания»: прямоугольник/квадрат нормально вставал в сетку только при угле 0°. Сейчас логика в `fabricSync.ts` / `GardenCanvas.tsx` учитывает смену местами ширины и высоты при углах 90°/270° и округляет углы до кратных 90° при активном snap.

### Что необходимо протестировать
- [ ] Поворот грядки (прямоугольник, ширина ≠ высота) на **90°** при snap ON — все 4 угла должны лежать на линиях сетки.
- [ ] Поворот на **180°** — объект остаётся в тех же границах сетки, не «съезжает» на полшага.
- [ ] Поворот на **270°** — корректный обмен width/height в привязке.
- [ ] Поворот **квадрата** на любой из кратных 90° углов — привязка не нарушается.
- [ ] Комбинация: поворот → перемещение → повторный поворот (проверка накопления ошибок округления центра).
- [ ] Комбинация: поворот → изменение размера (scale) → проверка, что размеры округляются до кратных шагу сетки в **локальных осях** повёрнутого объекта.
- [ ] Поворот с зажатой **Alt** (временное отключение snap) — свободный угол, после отпускания Alt snap снова работает корректно.
- [ ] Snap **OFF**: поворот ни на что не влияет, объекты свободно размещаются; при последующем включении snap существующие повёрнутые объекты **не перестраиваются**.
- [ ] Деревья (круги) и саженцы: round-shape не должен «прыгать» при повороте подписи/иконки внутри группы.
- [ ] Проверка после перезагрузки страницы / загрузки сохранённого проекта: angle из JSON восстанавливается, дальнейшее перемещение с snap корректно.

### Что необходимо переделать / доработать
- [ ] Рассмотреть **свободные углы** (не кратные 90°, например 30°, 45°): сейчас snap при таких углах может давать неточную привязку bounding box. Варианты решения:
  - привязывать центр AABB повёрнутого объекта к ближайшему узлу сетки без округления угла;
  - либо запретить non-orthogonal поворот при активном snap (округлять до 90°) — согласовать с дизайном;
  - либо реализовать привязку по corner points через обратное преобразование матрицы объекта.
- [ ] Вынести математику привязки повёрнутых объектов в утилиты с **unit-тестами** (vitest/jest) — сейчас проверка только ручная.
- [ ] Добавить визуальную индикацию ближайшей точки сетки при перетаскивании повёрнутого объекта (опционально, из Шага 6.1).
- [ ] Синхронизировать поведение rotate-контрола fabric (originX/originY центра) с расчётом snap-центра, чтобы исключить drift при серии быстрых drag-ов.
