# Архитектурные решения

## AD-001: Произвольные полигоны для грядок
**Дата:** 2026-09-21
**Решение:** Грядки и теплицы должны поддерживать произвольную форму (полигоны), а не только прямоугольники.
**Реализация:** Использовать `fabric.Polygon` вместо `fabric.Rect`. Инструмент рисования — клик по точкам + замыкание.
**Причина:** Реальные грядки часто имеют сложную форму из-за рельефа, дорожек, деревьев.

## AD-002: Размещение объектов не по сетке
**Дата:** 2026-09-21
**Решение:** Привязка к сетке — опциональна (toggle в Toolbar). По умолчанию — выключена.
**Реализация:** В Zustand store добавить `snapToGrid: boolean`. В логике размещения объектов проверять этот флаг.

## AD-003: Текст с привязкой к объектам
**Дата:** 2026-09-21
**Решение:** Текстовые подписи могут быть привязаны к объектам (двигаются вместе с ними).
**Реализация:** Добавить поле `attachedTo: string | null` в GardenObject. При перемещении родителя — перемещать дочерний текст.

## AD-004: Деревья как объекты со свойствами
**Дата:** 2026-09-21
**Решение:** Деревья — это не просто круги, а полноценные объекты с иконкой, свойствами, диалогом.
**Реализация:** Инструмент "Добавить дерево" → клик по canvas → появляется иконка дерева → открывается диалог свойств.

## AD-005: Быстрые кнопки для специфических объектов
**Дата:** 2026-09-21
**Решение:** В Toolbar добавить быстрые кнопки для часто используемых объектов: бочка, колодец, калитка, ворота, забор, яма с водой и т.д.
**Реализация:** Каждый объект — это `GardenObject` с `type: 'custom'` и `customIcon`. В инвентаре предустановлены базовые иконки.
