# Roadmap разработки GardenPlanner Pro

Этот документ описывает поэтапную разработку. 
ВАЖНО: При создании типов данных (TypeScript interfaces) и архитектуры стейта (Zustand) 
всегда закладывай поддержку будущих этапов, даже если сейчас мы делаем только Этап 1.

## Этап 1: MVP (Текущий фокус)
- Базовый Layout (Sidebar, Toolbar, Canvas, Properties).
- Canvas на Fabric.js: сетка, зум, загрузка фона с "замком".
- Базовые объекты: Дерево (название, сорт, год), Грядка (название, размеры).
- Переключатель годов (фильтрация отображения объектов по году).
- Сохранение/загрузка проекта в формат `.garden` (JSON).
- Базовая система инвентаря (статический список).

## Этап 2: Продвинутые объекты и Инвентарь (Следующий)
- Поддержка НЕСКОЛЬКИХ сортов на одном дереве (прививки).
- Вложенность: возможность размещать саженцы ВНУТРИ грядок и теплиц.
- Динамический инвентарь: пользователь может добавлять свои типы объектов с иконками.
- Привязка объектов к сетке (snap to grid).

## Этап 3: Учет, Аналитика и UI-полировка
- Поля для ввода урожая (кг) для каждого объекта по годам.
- Система оценок: Лайк 👍 / Дизлайк 👎 для сортов.
- Отдельная вкладка "Избранные сорта" (агрегация лайков/дизлайков за все годы).
- Садовый дневник (простой список записей с датами).

## Этап 4: Backend и Collaboration (Open Source / Production)
- Node.js + Express backend.
- PostgreSQL + Prisma ORM.
- Совместное редактирование в реальном времени (Yjs + WebSockets).
- Шаринг проекта по ссылке с правами доступа.
- Electron-обертка для десктопа.
